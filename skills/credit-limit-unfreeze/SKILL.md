# 重大预警额度解冻申请

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

客户主体、额度/借据合同、冻结原因及预警、当前还款与展期事实、接力贷方案、审批口径及额度解冻原模板。

## 执行

1. 先区分重大预警导致的授信额度冻结与存单解除质押；后者转cd-unfreeze-manual-funding，不混用通知书。
2. 逐项核触发事实、金额、他行展期及本行状态，依据原始凭证纠正口述差异；不把讨论中的接力贷当已批准。
3. 按原模板写冻结背景、当前情况、申请事项、拟办理路径、风险控制及授权依据；空缺数据另列，不能推定风险已解除。
4. 输出可复核申请与内部短句；解冻须实际审批和系统结果确认，备稿不完成主业务。

## 交付

原版额度解冻申请表、内部OA/沟通TXT、证据及缺项清单。

## 实现与依赖

- skills/loan-maturity-relay-and-credit-expiry/SKILL.md

申请模板与当前审批依据需授权提供；此为备稿规范，不具备银行系统解冻权限。
