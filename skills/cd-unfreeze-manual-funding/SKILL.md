# 存单解冻与手工备款

先读取[共用工作规则](../_shared/WORKFLOW.md)并以用户当前指令为准。收件箱默认只读；模板专项限制及实际证据优先，旧步骤中的写回或外发须符合本次授权。
1. 按客户号+合同编号+存单账号+批次分组，绝不混批。KP是业务批次号，BI是汇票序号，正式票据编号另列。
2. 读取存单证据核实本金、存单实际到期日、执行利率及实际本息。银承到期日不自动视为存单到期日。非工作日须核实营业部及集中作业中心安排。
3. 每批填写独立客户资料MD（金额单位元），使用原Word《存单解冻通知书》和OA模板，生成解冻通知书（含留底联）、现金等价物解除质押OA、公文分发手工备款OA。复用原Python金额大写转换；非整万元不得舍入。
4. 逐票将正式票据编号、票据到期日、票面金额（元）、出票人写入《支行需手工备款票据清单模板.xlsx》，先清空示例数据。BI序号只用于对照，不替代正式票据号。票号强制文本。
5. 校验每批票据张数、票面金额合计与合同金额一致；存单本金与银承面额差额仅为本金差额，最终补款需根据实际到期本息核算。
6. 每批交付客户资料MD、通知书DOCX、OA复制TXT、逐票备款XLSX、核验说明，统一打包ZIP；未确认日期须显著标记待核，不能作为可正式提交的成品。
7. GitHub仅存无客户数据的工作流说明与通用代码。客户真实资料不得提交公开仓库。草稿不代表OA提交、存单解冻、备款完成。
