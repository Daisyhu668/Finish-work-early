# 字段依据

| 字段 | 依据 |
| --- | --- |
| unit | 本笔实际经营单位，以已确认材料为准，不擅自改称 |
| borrower | 对应完整借款主体，不以经营者个人替代个体户 |
| identity_number | 主体证件或统一社会信用代码，不是客户号 |
| principal_yuan | 本次明确的人民币本金，单位元；自动生成大小写，不从余额推定 |
| amount / amount_upper | 已核币种金额的成对输入，人民币优先principal_yuan |
| loan_account | 本笔贷款账户，不是借据号或客户号 |
| repayment_account | 本次确认的还款账户 |
| credit_contract | 类型明确且与本笔对应的授信合同；额度合同号不自动等同，不清楚留空 |
| credit_limit | 有来源的客户或本合同授信额度，不能用余额或还款额 |
| loan_note | 已确认本笔借据；多个借据待明确或分别出表 |
| approval_authority | 本次有效授权材料，不套示例 |

所有值用字符串，附来源。未填项保持空白，不写“未知/待补”。签批意见、签名、公章及签批日期不代填。旧备注已还清与新待办冲突时保留冲突，不覆盖真实业务状态。Notion有日期的额度可预填，历史余额不作实时本金。先交付可完成部分，少量缺项放原待办。
