# 企业划型与ECIF佐证材料

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

正式企业名称、所属行业、财报、参保人数、经营范围原始资料、本次有效划型规则及用户原版Excel模板。

## 执行

1. 核对行业适用口径及年份，再分别核收入/资产/人数等适用指标与原始来源，不能用注册资本代替资产或参保人数当然代替全部从业人数。
2. 整理三证据包：财报PDF、参保人数PDF、经营范围PDF，保留来源、日期和主体；证据缺失不造PDF结论。
3. 按本次有效标准判断类型并写明依据、适用行业和指标口径，证据冲突单列，不择一隐藏。
4. 只填原Excel的企业名称、判定及说明等允许区域，保持表头、下拉和格式；模板缺失先交证据/字段包，不自建替代银行模板。

## 交付

三类证据PDF、原版Excel判定件及内部核对说明。

## 实现与依赖

- skills/_shared/WORKFLOW.md

已形成办理规范；固定Excel原模板及当前划型标准须在业务环境提供。
