# 业务分支与取数

| branch | 本期情形 | 输出 |
| --- | --- | --- |
| new | 新客户 | 原表+三PDF |
| annual_update | 存量年审更新 | 原表+三PDF |
| annual_no_update | 存量年审不更新 | 仅原表，下方划型项不填 |
| condition_change | 仅主要/非主要条件变更 | 原表称可无需划型，先核本期规定 |
| individual_business | 个体工商户 | 原表称不需提供，先核本期规定 |

财报用上一完整年度，审计报告优先、盖章财报次之；扫描件提候选后回看原图。资产总额不是注册资本，收入不是发票、纳税或流水；单体与合并不混用。非上年度必须有真实制度例外和period_exception_basis，不因需要结果而年化。

人数用上年期末从业，无期末再核全年平均。参保、从业、缴费人数不等同，外部仅有参保数时保留原名并补工资、医社保证明或盖章说明。行业不用人数参与门槛时，也不把人数PDF内容改写成不存在的事实。

行业按原表依次使用：审计主营构成、工商经营范围、多业态调查、实调合同/发票/回单、新成立可研/盖章说明。记录行业代码和划型分组的对应，不凭名字判断。金融业及铁路运输等不自动套其他未列明类。

智能查询依赖真实授权浏览器/服务；接口URL、费用和权限不预设为已接通。登录验证由用户完成，页面取证失败只补对应截图。结构化API数据不能冒充原截图。

内部记录主体/统一代码、判断日、年度、财报性质及范围、原值/单位/换算、人数口径、行业依据、规则文号版本、每页来源。正式四文件包不加入内部记录。
