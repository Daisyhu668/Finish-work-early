# 原模板与值编辑白名单

随包空白原表标题“企业划型检核表（2023年11月15日更新）”，来自用户此前提供的正式格式。已清除业务填值及未被固定正文引用的对应共享字符串，不含旧客户名；保留所有其他部件。指纹见assets/template_manifest.json。

| 单元格 | 允许写入 |
| --- | --- |
| A2 | 企业名称：企业全称 |
| B4/B6/B7 | 新客/年审更新/不更新适用说明，不适用为/ |
| B9 | 大型/中型/小型/微型 |
| B10 | 行业方法号及行业类别佐证材料命名 |
| B16 | 人数方法号及从业人数佐证材料命名 |
| B22 | 财务方法号及资产营收佐证材料命名 |

行业方法：1审计主营构成、2工商经营范围、3多业态调查、4实调及发票合同回单、5新成立例外。人数方法：1医社保证明、2盖章工资、3外部截图、4盖章说明、5新成立例外。财务方法：1审计报告、2盖章年度财报、3新成立例外。

B26/B27既有“客户经理已检视”“已上挂”按用户原约定保留，不能据此宣称本次实际状态或自动勾任务；交付单独提示经办核对。用户若明确要求调整状态先单独处理模板换版，不擅自扩白名单。

脚本只替换sheet1.xml中的白名单值，其他ZIP部件逐字节相同，工作表除目标值及存储类型外全部结构一致。换版指纹不同阻断，不自动修复。生成后在可用渲染/原生办公软件看长名称、方法文本、换行和分页；未视觉核验不能宣称所有显示均正确。

原表A27要求实际系统上挂时扫描检核表PDF；本次仍保留Excel+三PDF。需检核表PDF副本时走真实办公导出，不把xlsx改扩展名成PDF。
