# 规则与适用范围

原表引用厦门银行公〔2023〕1号《授信企业规模划型管理办法》及有效修订。现有素材未包含该办法全文，不声称已核其全部阈值。正式业务须在授权环境取得并核对有效规则配置。

公开参考来源：

- 工信部联企业〔2011〕300号：https://www.miit.gov.cn/jgsj/qyj/wjfb/art/2011/art_235af1ade45c4865957adeed23f9d949.html
- 统计上大中小微型企业划分办法（2017）：https://www.stats.gov.cn/sj/tjbz/gjtjbz/202302/t20230213_1902763.html
- 国家统计局分类标准问答第4、6、7、9问：https://www.stats.gov.cn/hd/cjwtjd/202302/t20230207_1902279.html

核验日期2026-11-09，公开检索未发现已生效取代上述文件的新版本；每次业务仍核当次有效性，修订消息/征求意见不能当生效规则。

public_rules.json逐行业配置小/中/大型下限，金额人民币万元，人数为人。双指标取最低档，例如工业20人、收入2000万元仍为小型；零是已证实零，未知不是零。缺一项时给可能区间，已知条件决定微型可给参考结论，但正式包仍要求齐全证据。

行内配置同结构，含真实policy_document、approved_version、effective_from和必要的effective_to。逐项对照有效制度并经授权核实后才可设bank_approved=true，不能只改公开规则标记。受控行内配置/制度正文不上传公共仓库。

结果不等同税务“小型微利企业”、人民银行贷款统计、普惠贷款门槛、规上企业或专精特新认定；需其他口径先切换标准。2011行业名称与2017小类代码需按适用映射核对，不任意泛化范围。
