# 账户费用优惠申请

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

机构/联系人、客户正式名称、申请日期、EVA及其期间、客户标签、关联方结论、拟优惠项目、适用收费及权限文件。

## 执行

1. 读取FeeDiscountTool的CATALOG和生成字段，只选本次适用的项目；历史收费标准和制度文号须逐项核当前版本。
2. 分别确认原执行标准、拟优惠标准、期限及审批权限，不能将源码自动生成的一年有效期或“非关联方”当已核事实。
3. 按客户输出优惠项目明细，复算相关金额；使用银行指定模板时必须填原格式，网页通用Excel导出不自动等同指定模板。
4. 起草申请事项、申请理由、建议处理意见及客户告知稿，区分拟申请与已批准；客户价值及后续合作承诺必须有依据。

## 交付

逐客户优惠Excel、OA申请Word及可复制TXT、客户沟通TXT。

## 实现与依赖

- components/tools/FeeDiscountTool.tsx

已有网页Excel导出与规则文案；现行标准及权限需另核。
