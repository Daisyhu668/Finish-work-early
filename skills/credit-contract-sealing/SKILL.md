# 授信合同封包与用印沟通

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

本次授信合同、已有账户资料、已法审协议版本、放款中心核验结果及封包/用印流程要求。

## 执行

1. 明确本次是授信合同，基于客户已有账号填列；开户合同另走开户流程。
2. 核合同字段、协议版本和放款中心是否已核；只有实际完成才能写“已核”。经核电子合同按要求封包后发送指定用印环节。
3. 对此前已法审协议是否需再次法审，按本次适用流程与变更情况核实，不泛化为任何变更都免审。
4. 按用户场景起草说明：字段填列→放款中心核对→封包→信托/总行用印，控制点为核过并封好的同一版本；不接受倒置的“先收已用印材料”处理顺序。

## 交付

可直接回复的沟通TXT、封包版本/字段核对表及OA草稿。
