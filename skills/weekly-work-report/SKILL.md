# 按客户汇总工作周报

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

明确报告期间、当前Todoist与Notion、已确认聊天进度、相关邮件及实际成果。

## 执行

1. 按客户整理期间实际动作，区分客户沟通、材料、报告、审批、签约、放款及系统办理；未操作的不能写已完成。
2. 每户保留本期进展、当前阻塞、下一步及预计时间；预计日期注明计划依据，不编造落地。已完成不重复当本期新增。
3. 晨会压缩为客户+昨日进展+当前动作+预计节点；周报按客户简明列示；月报另区分经营结果与过程。
4. 按用户本次指定的领导或渠道适配语气，不用星座替代实际偏好。自动成果纳入既有综合交付，不额外给同事或领导发消息。

## 交付

可编辑Word与直接汇报TXT；需要时附逐客户进度Excel。
