# 银承与存单测算

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

票面金额或存单本金、币种、银票起止日期、存单起止日期、存单执行利率、360/365计息基数及取整规则；分别确认一年期指哪个对象。

## 执行

1. 先读取两套网页源码，仅借用公式与字段；AcceptanceCalculator固定加六个月，不能直接承接一年期。UnderInvoiceWorkflow支持月数和到期日，但其联动测算使用银票日期，银票/存单日期不同时必须按实际存单计息期另算。
2. 使用本次确认的简单计息口径：到期本息=P×(1+r×d/b)，覆盖票面F所需本金P=F/(1+r×d/b)。r为年利率小数，d为已确认计息天数，b为确认基数。计息口径未确认时分别列360/365情景，不择一冒充批复。
3. 用十进制数精确到分，明确输入万元与内部元换算；分别列原始值、取整值、本息、票面及覆盖差额。若金额或日期非正、到期早于起息、字段冲突，停止正式测算。
4. 担保金额1.5倍、手续费默认值、利率和期限均不得直接取示例；实际银票期限准入由本次有效规则核验，网页能输入12个月不等于允许开一年期银票。

## 交付

测算Excel、参数及公式核对表、内部申请短句和客户微信TXT；注明测算方案、实际批复及执行结果的区别。

## 实现与依赖

- components/tools/UnderInvoiceWorkflow.tsx
