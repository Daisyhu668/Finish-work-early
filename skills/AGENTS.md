# 工作技能维护约定

- 本目录是Daisyhu668/Finish-work-early的日常银行工作技能统一维护区；新工作技能默认提交此处，不另开重复工作技能仓库。原有执行包路径保留。
- 先读catalog.json和source-map.json，再读取命中技能。目录不构成客户资料数据库，也不证明技能已在客户端安装或服务已部署。
- 每个技能必须有name/description、具体输入、可执行步骤、交付物、来源、依赖及失败边界。不得把纯页面、教程或占位按钮标成可自动办理。
- 新增/变更技能同步维护catalog.json、README.md及source-map.json。每个网页原目录项必须有明确去向；平台、开发、生活内容不混计银行业务技能。
- 编写业务规范前读取_shared/WORKFLOW.md；客户事实只留授权业务环境，公开仓库不得存真实客户数据、输入及已填成品。
- 固定原模板严格保留格式；只有用户授权公开且确认脱敏的空白原版随技能保存，专项本地限制优先。缺模板要登记依赖，不重绘替代。
- 保留既有脚本、资产和旧路径，避免复制维护两套规则。跨仓引擎通过明确来源路径加载，迁移后给旧入口指向新维护区。
- 验证全部目录项、依赖路径及任务路由；新增脚本须用合成数据实际运行。只修改说明/索引时检查差异边界，不宣称网站功能已改造。
- 用户最新指示高于旧技能。收件箱默认只读、草稿不勾业务完成、未知字段不编造、外发须有对应授权。
