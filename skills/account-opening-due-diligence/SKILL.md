# 开户尽职调查预填

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

本次原版调查表、客户主体/经营地址/行业、真实走访记录与照片、具体账户及本次办理意愿。

## 执行

1. 读取对应源仓库文件及原模板版本；开户核open-account的新开户尽职调查表网页版.py，销户核openandclose/closegen.html和close_template.docx。旧文件需先清除案例、预填结论和隐藏客户信息。
2. 只写实际已核字段；现场经营和照片须有本次事实及来源，不从旧报告复制成新走访。模板不匹配则停止填充，先交字段表。
3. 固定原版副本填写，保留印鉴、签名及调查意见栏；不能因脚本支持占位符就自行改模板。
4. 渲染Word核对表格、图片、分页及旧数据；实际开户/销户由银行结果确认。

## 交付

原格式调查表预填Word、已填/缺项核对清单和柜面材料TXT。

## 实现与依赖

- https://github.com/Daisyhu668/open-account

源仓库保留代码和历史模板；当前技能为统一办理入口，须取本次授权原模板，不重复上传未经检查的旧模板。
