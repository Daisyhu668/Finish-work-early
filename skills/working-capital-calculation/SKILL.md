# 流动资金贷款需求测算

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

同一主体、同一口径的系统财务指标表及两期数据，缺失时用原始财报；本次原版测算表和有效公式、融资/自有资金来源。

## 执行

1. 优先读取系统财务指标表，资产负债周转项目用两期平均；缺失才按报表提取，记录替代来源和原因，合并与单体不混算。
2. 逐项列收入、成本、利润率、应收/预付/存货/应付/预收平均值与各周转指标；严格按本次表定义，分母为0或缺失不强行得天数。
3. 保留原始数据测算；调整时另列调整项目、原值、调整值、依据及结果，不覆盖原始测算，不靠倒算满足额度。
4. 核自有资金、既有流贷及其他营运资金来源的真实口径，避免重复扣减或将授信额度当已用余额；解释结果与本次申请的关系。

## 交付

原始+调整两套Excel测算、来源与调整说明、授信报告可用短段。
