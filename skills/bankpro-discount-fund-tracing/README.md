# 银承近期贴现核查 Skill

安装：把本目录放入 Agent 的 skills 目录（例如项目 .claude/skills/ 或 .agents/skills/），由 Agent 按 SKILL.md 调用；具体支持路径取决于运行环境。本仓库已通过工作技能路由索引提供统一入口。

示例：某客户今天开票，查询征信近一周有贴现，请按上传的两家银行流水生成贴现情况说明、重命名和合并流水，开票资金为企业自有资金。

安装依赖后执行 python -m unittest discover -s tests -v。技能包不含真实客户流水；真实材料仅保留在业务交付包内。采用Agent复核+脚本计算和归档，不是无人值守全自动OCR，也不会自动查询征信或提交银行系统。
