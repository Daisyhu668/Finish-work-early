# 批量开票文书与明细

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

原版Word/Excel模板、经确认的填充脚本或字段映射、单户单批主体/账号/合同及逐笔收款人信息。

## 执行

1. 先核原模板和实际生成脚本是否存在。BatchBillingTool的下载/生成按钮目前仅toast提示，不能点击后宣称已生成或存在可下载工具包。
2. 为当前单户单批建立字段映射，区分总表字段与逐笔字段；收款人名称、账号、开户行、金额逐行核对，编号作为文本。
3. 校验逐笔金额合计、本期总额、合同及存单数据；核实模板允许的占位符或输入区域，复制模板后填值，不重新绘制格式。
4. 缺模板/脚本时先产出真实数据明细与字段清单，并调用under-invoice-workflow交付能完成的TXT，不给空文件或伪Word扩展名。
5. 模板可用时按文件处理流程填充并渲染，读回逐笔核对；记录本批输入版本和产物，输入不变复用。

## 交付

逐笔Excel、字段映射/缺件清单、可完成的开票材料；只有原模板齐全并验证后才交正式模板填报件。

## 实现与依赖

- components/tools/BatchBillingTool.tsx
- components/tools/UnderInvoiceWorkflow.tsx

当前网页批量下载及文书生成是占位实现；正式文书依赖用户原模板，不能当作已实现的一键工具。
