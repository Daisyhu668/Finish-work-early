# 银行原始模板（仅在授权本地保存）

本公开仓库**不包含**任何银行内部原版模板或客户真实业务资料。请在授权的本地Windows工作环境中，将以下两份由银行系统导出的**未经修改的原版**文件放到此目录：

- `InvoiceLogInfo.xls`：第一阶段“发票登记／提前核验”模板。
- `InvoiceInfo.xls`：第二阶段“已选发票与BI汇票号关联”模板。

使用须知：

1. 两个文件的名称、扩展名、Sheet、下拉验证、星号必填列、单元格格式等均保持原样。
2. 脚本以模板副本写入单元格值，绝不编辑原件；原版下载变化时应重新校验模板版本。
3. 不要将真实客户发票、对公账号、交易合同、BI号及银行原版模板提交GitHub，也不要在在线转换网站处理。
4. 需在Windows且有Excel COM组件的授权环境完成原生xls保真写入；其他环境只能作数据整理与关联计划。

参见 ../references/workflow.md 和 ../references/templates.md。
