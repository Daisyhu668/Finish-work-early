# 客户经理KPI自评与冲刺分析

先读取[共用工作规则](../_shared/WORKFLOW.md)，再执行本技能。

## 输入

本次与上次KPI原表、考核办法/基数、报表日期、本人当前认领与实际转入计划、经营中台口径。

## 执行

1. 先核数据期次、工号、分项权重、达成率、得分及排名样本；当前表优先，历史记忆不替代最新指标。
2. 逐项复算差异，区分业务变化、基数变化、规则变化及同业排名变化；经营中台年初基数与KPI月度变动基数分别算。
3. 存量转认领不自动算新增；新增存款起算月、日均/余额、有效户、授信、贴现及风险等按本次规则验证。测算候选动作的边际得分、可实现性和潜在负贡献。
4. 输出有依据的两个月/剩余期间重点与领导自评；无法验证的分数只列条件情景，不写成确定可得分。

## 交付

逐指标Excel、差异及认领情景表、简洁领导汇报Word/TXT。

## 实现与依赖

- skills/_shared/WORKFLOW.md

需要本次实际报表与考核公式，不能从旧排名或认领金额直接推算当前得分。
